A Agentic AI

A-01

MyAnalyst — Autonomous Data Analysis Agent

  1. Data + docs
  2. LangGraph router
  3. Plan → code
  4. Docker sandbox
  5. Cited answer
Problem
Answering business questions means juggling spreadsheets, policy documents and ad-hoc analysis code.
Method
A LangGraph agent routes each question to quant, document or hybrid tracks, writes pandas code, runs it in a network-isolated Docker sandbox and retries on failure.
Result
Proactive EDA and forecasts on upload, plus answers that check computed numbers against targets in the documents, with citations.
  • Python
  • LangGraph
  • FastAPI
  • pgvector
  • Docker
  • DeepSeek
A-02

MySaidi — AI Productivity Assistant

  1. Chat
  2. LangGraph agent
  3. Groq LLM
  4. PostgreSQL
  5. PWA
Problem
Managing tasks, calendars and habits across apps is friction-heavy.
Method
A LangGraph agent on Groq parses intent from natural conversation and edits the user’s schedule directly.
Result
A secure, installable PWA with JWT auth — plan your day by just talking to it.
