AI & Machine Learning

MySaidi - AI productivity Assistant

A full-stack personal AI productivity assistant web application. It helps users plan their day, manage tasks, and track habits through natural conversation with an AI agent. The AI, named Saidi, uses natural language to add, update, remove, or review calendar events and tasks. It includes a dashboard, a calendar view, a habit tracker, and secure JWT authentication. The app functions as a Progressive Web App (PWA) with a mobile-optimized UI.

The system uses a decoupled browser-to-REST API architecture. The frontend is a vanilla JS/HTML/CSS SPA served directly by FastAPI. The backend handles PostgreSQL database operations (Users, Tasks, HabitLogs) and routes chat requests to a LangGraph-powered AI agent. The agent parses intents, runs Groq LLMs, and triggers bound tools to directly query or modify the user's schedule.

Behavioural Explainer

This system is a production-grade Retrieval-Augmented Generation (RAG) system for psychological framework analysis. It ingests and chunks psychological PDF documents, stores them in a vector database, and uses a local LLM to analyze user-provided human interaction scenarios. It strictly avoids offering advice, instead breaking down the scenarios into core conflict identification, operative psychological frameworks, behavioral mechanics, and structural signatures.
